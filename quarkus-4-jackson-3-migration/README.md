# Quarkus 4.0 Jackson 3 migration

Shows the Jackson 3 builder-style mapper configuration (`tools.jackson.databind.json.JsonMapper`) that Quarkus 4.0 moves to, with tests pinning the behavior flags.
Run it with `mvn verify` on JDK 21 or newer.
