# spring-ai-decision-models

Shows the Spring AI 2.1 `DecisionModel` API: a ticket router that asks a yes/no, a choice and a score question in one call and applies thresholds to the probabilities.
The tests use a stubbed `DecisionModel`, so no model, Ollama or API key is needed. Run it with `mvn verify`.
