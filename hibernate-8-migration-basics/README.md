# Hibernate ORM 8.0.0.CR2 migration basics

Bootstraps Hibernate ORM 8.0.0.CR2 against in-memory H2, then shows an explicit sequence allocation size, a constructor expression instead of result transformers, and a stateless insert that compiles on 7.x and 8.0.

Run it with `mvn verify` on JDK 21 or newer.
